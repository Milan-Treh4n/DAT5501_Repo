This project is a simple data science validation pipeline that tests how line fitting behaves with small, medium, and large datasets. The goal was to generate synthetic data following the equation y = 2x + 5, add some random noise, and then use Python to fit a line back to the data. I started with smaller datasets to check the process and then scaled up to medium (50 points) and large (100 points) datasets to see how the fit accuracy and plots changed. For the medium and large versions, I also added random error bars to simulate measurement uncertainty and used weighted regression to account for it. 

The results showed that as the number of data points increased, the fitted line became more stable and accurate, even with noise present. The smaller datasets had slightly more variation in the slope and intercept values, while the larger datasets produced smoother and more consistent fits. Each dataset and plot was saved as a CSV and PNG file, and automated tests were created to check that the data and plots were generated correctly, that all values were numeric, and that the fitted parameters stayed close to the expected values. Everything is linked to a CircleCI pipeline so the tests run automatically whenever new changes are pushed to GitHub. Overall, the pipeline demonstrates how data size and uncertainty affect line fitting and how continuous integration can help validate and maintain data workflows.
