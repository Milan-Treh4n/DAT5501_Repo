This project analyses global life expectancy using polynomial regression models of order 1–9. It performs two major tasks:
Forecasting life expectancy
Fits polynomial models using all but the last 10 years of data
Forecasts the final 10 years
Visualises orders 1–9 for continents or global averages
Model testing using χ² per degree of freedom
Fits polynomial models (orders 1–9) to the training data only
Computes the goodness-of-fit statistic χ²/ν
Identifies the best model order
Saves comparison plots for use in the report
All analysis is based on the dataset life_expectancy.csv.
